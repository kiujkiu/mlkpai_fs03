## 0. 结论速览

| 问题 | 结论 |
|---|---|
| 13rps (=26 volume fps) 能不能压进 213.7µs/片 | **能, 但只在全流水 FSM 下**: 211.9µs/片, 余量 **+0.85%**。非流水 (LE/消影/换行串行插入) 是 292.7µs, 短 27% — FSM 流水化不是优化项, 是**硬前提** |
| 3.3V 单端 50Mbps 过这条链路 | **有条件可行**: RSS 偏斜余量 ≈ 3~6ns / 20ns 窗; 线性最坏叠加只剩 ~2ns。前提: ① 转发时钟 90° 居中 ② 50pin 排线 ≤0.5m ③ 串扰实测 <2.5ns |
| 最大 SI 风险 | **50pin 排线串扰/SSO** (双屏 38+ 信号共缆、地线极少、18 根数据 lane 同沿翻转), 其次屏内 245 扇出对偏斜与 CLK→SOUT 级联延迟 |
| 降级第一档 | 20MHz 双沿 = 40Mbps: 每片 264.6µs → 13rps 需把切片降到 **290 片/转** (角分辨率 1.24°), 或维持 360 片降到 10.5rps |

⚠ 芯片型号提示: `led_panel_chain.md` 记录现屏列驱实贴为 **ICND2049** (双缓存, 协议兼容 2038S, FCLK 25MHz)。本文全部 AC 参数按 **ICND2047 V2.0** 手册取值 (双沿触发是 2047 的明文特性)。若新屏实贴 2049, **上板前必须用 2049 手册 (微信文件) 复核 §1 表格**, 尤其"双沿采样是否存在"这一条 — 2049 手册若只写 CLK 上升沿移位, 则 50Mbps 方案整体不成立, 直接跳 §5 降级档 4。

## 2. 刷新预算逐项账 (25MHz 双沿, 96 CLK/行 × 54 扫)

行数据量核对: 12 颗级联 × 16bit = 192 bit/lane/行; 双沿 192 bit = **96 CLK 周期** ✓ (与 02 文档 9 lane × 54 row × 24B = 11664B/片一致)。
现役锚点: v4.1 单沿 25Mbps 实测 2.37kHz → 7.81µs/行 = 192 CLK 移位 7.68µs + **行开销实测仅 ≈0.13µs (≈3.3 CLK)** — 证明现 FSM 已把 LE/换行叠进移位尾部, 流水化路线有实现先例。

### 2.1 方案 A — 全流水 (基线方案, 推荐)

流水原则 (2047 双缓存正是为此设计, 手册"提高刷新率的原理"一节):
- LE(3/4/5) 叠加在本行移位的**最后 3/4/5 个沿**上 → 额外 0 CLK;
- Tghost 与行切换发生在 OE=H 期间, 与**下一行**的数据移位并行 → 不占行周期, 只吃显示占空比;
- 3019 行驱链 (A/B/C 线, DCLK≥500ns) 在下一行移位窗口 (3.84µs) 内完成 → 不占行周期。

| # | 项 | 单行 | 54 行合计 | 备注 |
|---|---|---|---|---|
| 1 | 移位 96 CLK × 40ns | 3840 ns | 207.36 µs | 硬底, 占预算 97.0% |
| 2 | LE 沿 (3/4/5) | 0 ns | 0 | 叠加移位尾部 |
| 3 | 行间隙 (LE↓→下一行首 bit, FSM 保 tHOLD2 + 相位重整) | 80 ns (2 CLK) | 4.32 µs | |
| 4 | 消影 Tghost + 行切换 (3019) | 0 ns | 0 | 并行于下一行移位, 见 §2.3 占空账 |
| 5 | 首行 LE=5 差额 + 片头流水起灌 | — | ≈0.2 µs | 每片一次 |
| | **每片合计** | 3920 ns/行 | **211.9 µs** | |

**实际可达刷新率 = 4.72 kHz/屏**。需求 4680 片/s (13rps × 360):

| 指标 | 数值 |
|---|---|
| 213.7µs 预算内余量 | 213.7 − 211.9 = 1.8 µs = **+0.85%** |
| 等效转速上限 @360 片 | 13.11 rps |
| 26 volume fps (双屏各 13rps, 180° 相位) | 同一预算, **同样 +0.85%** — 双屏 lane 独立并行, 不 ×2 |

**余量定性: 压线通过。** +0.85% 吃不下任何 FSM 停顿 (比如每行多插 2 CLK 就转负)。两个免费的弹性阀:
- 切片 360→352: 余量 +3.1% (角分辨率 1.023°, 视觉无感);
- rps 13→12.8: 余量 +2.4% (volume 25.6 fps)。
建议 RTL 里 slice 数做成寄存器可调, 验证阶段用 352 起步, 稳定后再收 360。

### 2.2 方案 B — 非流水对照 (为什么必须流水)

| 项 | 单行 | 54 行 |
|---|---|---|
| 移位 96 CLK | 3840 ns | 207.4 µs |
| LE=4 串行插入 (2 CLK) | 80 ns | 4.3 µs |
| Tghost 串行等待 (取 1µs) | 1000 ns | 54.0 µs |
| 行切换 3019 (1 DCLK≥500ns + RCLK) | 500 ns | 27.0 µs |
| **合计** | 5420 ns | **292.7 µs** → 3.42kHz, 只够 9.5rps, **短 27%** |

### 2.3 Tghost 与显示占空比 (不占刷新, 占亮度)

Tghost 期间 OE=H (显示关断), 在流水方案里被下一行移位窗遮蔽, 但每行的**点亮占空比** = 1 − (Tghost + 行切换)/3.92µs:

| Tghost 取值 | 占空比 | 说明 |
|---|---|---|
| 1.0 µs (保守, 2038S 系工程惯例) | 74.5% | 首点亮用这档 |
| 0.5 µs | 87.2% | 增强消影模式 (Reg2[8/5/3]=111) + R_FALL_TIME=35ns 后的目标档 |
| 0.3 µs | 92.3% | 实测无鬼影再收 |

调参判据: 全黑背景单行白, 看上/下邻行鬼影; Tghost 从 1µs 二分下探。

## 3. 双沿时序预算 (20ns/bit 窗)

### 3.1 链路电气模型

驱动: Zynq Bank13 LVCMOS33 (J1 跳帽已 3.3V), Ro ≈ 25~35Ω (12mA 档) → **串阻 33Ω (FS03) + 10Ω (接口板) → 总源阻 ≈ 70~80Ω**。
负载: 50pin 排线 (~50pF/m) + 两级转接板走线 + 屏侧 245 输入 (~5pF), 按排线 0.5m 估 **C ≈ 50pF** → τ ≈ 4ns, 10–90% 沿 ≈ 8.8ns。
接收阈值: 屏侧 245 VCC=**3.8V** → VIH=2.66V / VIL=1.14V。RC 指数沿穿越 1.14→2.66V 的不确定带 ≈ **4.9ns** — 这是每个 bit 窗里被沿速率吃掉的部分。

### 3.2 Timing budget 表 (数据 lane 对 DCLK, 每沿)

| # | 项 | 值 (ns) | 依据/假设 |
|---|---|---|---|
| A | bit 窗 (50Mbps) | 20.0 | |
| B | 2047 tSETUP1 + tHOLD1 | −10.0 | §1, 5+5 |
| C | RC 阈值带差额 (CLK 与数据 τ 不同, 取带宽的 ±30%) | ±1.5 | 负载/走线差异, 待实测 |
| D | ODDR 对偏斜 (同 bank IOB, CLK vs 数据) | ±0.6 | 7 系 HR bank, TCKDO 匹配 |
| E | DCLK 占空失真 (MMCM DCD + ODDR) | ±0.5 | 侵蚀相邻窗 |
| F | MMCM 输出抖动 | ±0.3 | |
| G | FS03 J12 等长残差 | ±0.1 | 板上已全等长 |
| H | 50pin 排线线间偏斜 | ±0.3 | 同缆等线长 |
| I | 接口板 + 转接板走线差 (未等长, 按 ±10cm) | ±0.6 | 两块米联客板无等长承诺 |
| J | 屏内 245 扇出: CLK 与数据走**不同 245 芯片**的传输延迟差 | ±1.5 | 9 组信号多颗 245, 板级不可控 |

| | 偏斜线性和 (C~K) | ±7.9 | |
| | 偏斜 RSS | ±3.5 | |
| | **余量 (线性最坏)** | 20 − 10 − 7.9 = **+2.1** | 勉强为正 |

### 3.3 两个专项风险

1. **twCLK 零容差**: 25MHz 双沿下 CLK 高/低各恰 20ns = twCLK min。MMCM 占空失真 ±0.5ns + 串扰在 CLK 沿上的推挤都会直接违反手册。对策: MMCM 该输出显式设 DUTY_CYCLE 0.500, 排线里给 DCLK 找最安静的邻居 (现 pin22, 两侧是 LAT/SPIN_SYNC — LAT 只在锁存沿翻转且与 CLK 同步, 尚可; 见 §4)。
2. **判定: 3.3V 单端 50Mbps 有条件可过**。RSS 口径余量 3~6ns 成立的三前提: 转发时钟 90° 相移居中 (§6)、排线 ≤0.5m、K 项实测 ≤2.5ns。任一不成立 → 走 §5 降级档。

## 4. SI 风险分级与对策

### 4.1 风险分级

| 级 | 风险 | 机理 | 对策 |
|---|---|---|---|
| **高** | 排线串扰 + SSO | 50pin 缆同时载双屏两组信号 (J12 pin3~23 屏1 组, pin24 以后屏2 组), 邻 pin 全是信号、地回流稀缺 (pin2 一根为主); 双沿下 18 根数据 lane 每 20ns 同沿翻转, 回流挤在少数地线 → 地弹 + 线间耦合直接打在 2.66V VIH 只剩 0.64V 的高电平余量上 | ① **两屏 DCLK/数据组相位错开 90°** (屏2 的 ODDR 用 clk 相移副本) — 同沿翻转数减半, SSO 峰值近半; ② 排线压到 ≤0.3m; ③ Bank13 数据 lane DRIVE 从 12mA 降 8mA 试 (沿慢 → 串扰降, 用 §3 预算换); ④ 若可换缆, 换 1:1 隔地排线 (信号:地=1:1) 是终极解 |
| **中高** | 屏内 245 扇出对偏斜 (J 项) | CLK 与本 lane 数据经不同 245 芯片, 芯片间 tpd 差 1~2ns, 板级无法优化 | 只能靠 90° 居中吸收 + 实测确认; 若超 → 降频 |
| **中** | 反射/振铃 | 源端 70~80Ω vs 排线 Z0≈100~150Ω, 欠端接; 源端反射系数 ≈ −0.2~−0.3, 二次反射在接收端造成 ~0.2~0.3 摆幅的 ringback, 距 VIH 2.66V 的余量窄 | 33Ω+10Ω 双串阻的作用: 33Ω 是主阻尼 (贴 FPGA, 源端串联端接), 10Ω 把接口板→屏段再分段阻尼、并抑制 P1/P3 分叉处的短桩振铃 — 保留, 不要为"提速"短接; ringback 判据入 §4.3 眼图 |
| **中** | DCLK 占空/偏斜 (§3.3) | twCLK 零容差 | MMCM duty 显式约束 + 示波器直测 CLK 高/低宽 ≥19.5ns |
| **低中** | 级联 CLK→SOUT | tpd2 typ 20~30ns @3.3V vs 双沿 20ns 沿间隔 — 纸面上第 N+1 颗芯片采样窗与前颗 SOUT 翻转擦边。此为**屏内芯片间时序, 厂家按 25MHz 双沿设计背书**, 板级无手段 | 用 walking-1 图形专门打芯片边界 (bit15/16, 31/32 …), 错则整屏降频, 无中间对策 |
| **低** | 3019 行驱链 | A/B/C 线仍是低速 (DCLK≥500ns 已知坑), 双沿改造不碰它 | 沿用现时序 |

### 4.2 实测验证方案

单 lane 试跑 (先于全链):
1. 只启用 R1 lane + DCLK + LAT, 其余 lane 驱动恒 0 → 灌 walking-1 + 0x5555/0xAAAA (双沿最坏翻转) + 棋盘, 屏上人工核; 10min 烤机看闪点。
2. 逐步放开 lane 数 1→3→9→双屏 18, **每一步重测**: 串扰是 lane 数的函数, 单 lane 通过不代表结论。
3. 频率阶梯: 12.5MHz 双沿 (=25Mbps, 电气等价现役锚点) → 20MHz 双沿 → 25MHz 双沿, 每档全套图形。

示波器测点 (探头地弹簧, 不用长地线夹):
| 测点 | 看什么 |
|---|---|
| ① FS03 J12 pin22 (DCLK 源端) | 发射波形基准; CLK 高/低脉宽 ≥19.5ns (twCLK) |
| ② 转接板 BTB 处 = 屏 J1 pin10 (DCLKIN) / pin24 (R1IN) | **接收端眼图主测点** (245 输入前, 链路终点) |
| ③ 屏 J1 pin24 (R1) 静止时 + 其余 17 lane 打 0x5555 | 串扰幅度直读 (victim 安静法), 得 K 项实测值 |
| ④ 接口板 P1 pin8 (中间级) | 反射定位: 与 ②对比看 10Ω 前后波形 |
| ⑤ FS03 3V3/Bank13 电源 pin (就近 decap) | SSO 地弹, 18 lane 同翻时 |

眼图判据 (测点 ②, 无限余辉, DCLK 双沿触发, ≥30s 积累):
- **眼宽 ≥ 12ns** (tsu 5 + th 5 + 2ns 抖动储备) / 20ns 窗;
- **眼高**: 高电平底线 ≥ 2.9V (VIH 2.66 + 0.24 余量), 低电平顶线 ≤ 0.9V (VIL 1.14 − 0.24);
- ringback 不回穿 2.66V / 1.14V ± 0.15V;
- 串扰专项 (测点 ③): victim 上感应峰峰 ≤ 0.5V。
任一不达 → 记录差多少, 直接映射到 §5 档位选择。

## 5. 降级预案

刷新率 = 54 行 × (96 CLK + 2 CLK 间隙) / f_bit 的函数; 两个旋钮 = 转速 rps、切片数/转:

| 档 | 时钟方案 | 数据率 | bit 窗 | 每片时间 | 刷新率 | 维持 360 片 → rps | 维持 13rps → 片数 (角分辨率) |
|---|---|---|---|---|---|---|---|
| 0 (目标) | 25MHz 双沿 | 50Mbps | 20ns | 211.9 µs | 4.72 kHz | **13.1** | 363 → 用 360 (1.00°) |
| 1 | 22.2MHz 双沿 | 44.4Mbps | 22.5ns | 238.4 µs | 4.19 kHz | 11.7 | 322 (1.12°) |
| 2 | 20MHz 双沿 | 40Mbps | 25ns | 264.6 µs | 3.78 kHz | 10.5 | **290 (1.24°)** |
| 3 | 16.7MHz 双沿 | 33.3Mbps | 30ns | 317.5 µs | 3.15 kHz | 8.75 | 242 (1.49°) |
| 4 (回退底) | 25MHz 单沿 (=现役 v4.1) | 25Mbps | 40ns | 422 µs (实测) | 2.37 kHz | 6.58 | 182 (1.98°) |

- 档 2 (20MHz 双沿) 是首选降级: bit 窗多出 5ns 全部进偏斜预算 (K 项容限 2.5→5ns, 线性最坏余量 +2.1→+7.1ns), 且 twCLK 高/低宽 25ns > 20ns min 恢复 5ns 占空容差 — **SI 三大专项同时解压**; 代价是 13rps 下角分辨率 1.24° 或 360 片下 10.5rps (volume 21 fps)。
- MMCM 上把 f 做成两档可切 (25/20MHz 双沿), 上板用寄存器/重配置切换, 不重编译。
- 档间还有连续刻度: 任意 f 下 rps@360 = 1/(360 × 54 × 98/(2f)); 片数@13rps = 2f/(13 × 54 × 98)。

## 6. XDC 约束要点

时钟结构: MMCM 出两相 — `clk0` (数据 ODDR + fabric FSM), `clk90` (转发 DCLK 的 ODDR)。90° = 10ns, DCLK 沿天然居中于数据 bit 窗, 把 §3 偏斜预算从单边判改成对称判。双屏时屏2 再取一对相移副本 (§4 SSO 对策)。

```tcl
# 1) 转发时钟: DCLK 用 ODDR 输出 (C=clk90, D1=1, D2=0), 声明生成时钟
create_generated_clock -name dclk_fwd \
  -source [get_pins mmcm_i/CLKOUT1] -multiply_by 1 [get_ports panel_dclk]

# 2) 数据 ODDR (C=clk0, SAME_EDGE) — 双沿 output delay, 四条一组
#    tsu=5 th=5, 板级偏斜预算 bd=2 (I+J 项分给板级的额度)
set tsu 5.0 ; set th 5.0 ; set bd 2.0
set dports [get_ports {panel_r1 panel_g1 panel_b1 panel_r2 panel_g2 panel_b2 panel_r3 panel_g3 panel_b3 panel_lat}]
set_output_delay -clock dclk_fwd -max [expr {$tsu + $bd}] $dports
set_output_delay -clock dclk_fwd -min [expr {-($th + $bd)}] $dports
set_output_delay -clock dclk_fwd -max [expr {$tsu + $bd}] $dports -clock_fall -add_delay
set_output_delay -clock dclk_fwd -min [expr {-($th + $bd)}] $dports -clock_fall -add_delay
# clk0/clk90 是同 MMCM 相移, Vivado 自动按 5ns 最近沿分析 → 时序报告里
# setup 检查窗即 "90° 居中" 后的真实余量, 不要 set_false_path
```

要点:
1. **必须 ODDR 转发 DCLK** (D1=1/D2=0), 严禁 fabric 逻辑直出时钟 — 否则 CLK/数据走不同延迟路径, D 项从 0.6ns 涨到不可控。
2. 数据 ODDR 用 `SAME_EDGE` 模式, 两个 bit 都在 clk0 上升沿喂入, FSM 单沿逻辑不变。
3. **Bank13 是 HR bank, 7 系 HR 无 ODELAY** → 没有 per-lane 输出去斜手段, lane 间对齐完全靠板级。FS03 J12 已全等长 (G 项 ±0.1ns) 正好补掉这个缺口 — 这是 Bank13 等长的真正价值; 接口板/转接板的 ±0.6ns (I 项) 是全链唯一无约束段, 若日后改板把两级转接板 lane 组做等长, I 项即归零。
4. MMCM 输出显式 `DUTY_CYCLE 0.500`; timing 报告确认 dclk_fwd 到 panel_dclk 的 min/max 输出路径差 <0.3ns。
5. LAT 与数据同组约束 (tSETUP2/tHOLD2 同为 5/5ns), 不要漏。
6. 双屏第二组端口 (`*_2`, W8/V8/W7 …) 复制同一套约束, 用相移副本时钟单独 `create_generated_clock`。
